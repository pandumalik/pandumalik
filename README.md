I bridge the gap between development, operations, and security, with a deep focus on **DevSecOps**—weaving security layers directly into the development lifecycle.

### ⏳ The Story So Far

<details>

- **2012 - The Spark:** Won a gold medal at the regency level in a national IT competition (OOSN). Bought an iPhone 4 with the prize money, jailbroke it, and hardware-modded it to have a glowing Apple logo like the MacBooks.
- **2013-2018 - Foundation:** Studied Information Systems at Telkom University, Bandung. Explored software architectures and web development.
- **2018 - The Professional Entry:** Started as a Java Developer in a Jakarta multifinance company, eventually leading mobile development with React Native and Flutter.
- **2021 - System Design:** Moved to a public transport company as an Architecture Analyst, designing scalable and robust system frameworks.
- **2022 - Scaling Up:** Switched back to multifinance as an SRE/DevOps Engineer, managing CI/CD pipelines, automating infrastructure, and keeping systems resilient.
- **Present - Securing the Loop:** Pursuing a Master's degree in Cybersecurity & Digital Forensics (via Komdigi scholarship) with a thesis focused on integrating security layers directly into DevSecOps lifecycles.
